# Valley Standard business operations project

This repo is the operating home for Valley Standard business setup and launch work. The website is already live as a static GitHub Pages site, so this project plan focuses on the business board, issue taxonomy, and starter backlog needed to run the business without duplicating work already completed in the earlier planning session.

## Carry-forward context

- Public brand direction is **Valley Standard**.
- Legal / operating name direction is **Valley Standard Property Management LLC**.
- The site is intentionally positioned as **Coming Fall 2026**.
- The website and domain setup are already in place in this repo.
- The OREA property manager application has been started.
- The next business-lane setup from the prior plan was LLC formation, followed by EIN, banking, insurance quotes, and city licensing.

## Project fields

| Field | Type | Values / use |
| --- | --- | --- |
| Status | Single select | Backlog, Ready, In progress, Waiting, Blocked, Done |
| Priority | Single select | High, Medium, Low |
| Area | Single select | Licensing, Banking, Insurance, Google Business Profile, Website / form, Lead pipeline, Vendors, Compliance, Launch, Finance / pricing, Operations |
| Sprint / iteration | Iteration | Two-week cycles |
| Launch phase | Single select | Foundation, Compliance ready, Market presence, Operations ready, Lead pipeline, Fall 2026 launch |
| Owner | Person | Accountable owner |
| Due date | Date | Real due date or review date |
| Dependency | Text | Blocking issue, outside party, or prerequisite |
| External link | Text | Filing, receipt, official source, spreadsheet, vendor quote, or doc |

## Recommended views

| View | Filter / grouping | Purpose |
| --- | --- | --- |
| Backlog | Status is Backlog or Ready | Default triage queue |
| Current sprint | Current iteration, Status not Done | Two-week execution view |
| Launch readiness | Group by Launch phase | See the path to Fall 2026 launch |
| Compliance lane | Area is Licensing, Banking, Insurance, or Compliance | Keep regulated work visible |
| Leads and market presence | Area is Leads, Google Business Profile, Website / form, or Vendors | Track demand generation and referral work |
| Blocked / waiting | Status is Waiting or Blocked | Weekly follow-up queue |

## Milestones / launch phases

1. **Foundation**: LLC, EIN, operating account, project board, document storage, baseline budget.
2. **Compliance ready**: OREA course/exam/license, registered business name, trust-account readiness, city license, management agreement, owner/tenant compliance checklist.
3. **Market presence**: Google Business Profile, website lead form endpoint, business email, warm referral list, local networking rhythm.
4. **Operations ready**: vendor bench, owner onboarding, maintenance workflow, lead pipeline stages, bookkeeping process, service package.
5. **Fall 2026 launch**: publish launch-ready website copy, activate outreach, test intake-to-onboarding workflow, review go/no-go checklist.

## Board hygiene

- Keep business setup tasks as issues, not loose notes.
- Use decision records for durable choices such as pricing, service scope, operating boundaries, and launch timing.
- Open follow-up issues instead of expanding one issue beyond a single outcome.
- Close issues only when the definition of done is satisfied and any source links or receipts are attached.
- Avoid duplicating carry-forward completed work: brand selection, initial website build, domain setup, and starting the OREA application should be referenced as context, not reopened as new work.
